Module 1: Assignment-Linux and GIT Command Cheat Sheet

Linux and GIT:
1. Linux: ls - list contents of directory
2. Linux: cd - change directory
3. Linux: mkdir - create directories
4. Linux: pwd - get path of present directory
5. Linux: cat - display file contents in terminal
6. Linux: mv - move or rename files
7. Linux: rm - delete files or directories
8. GIT: git branch - lists your branches
9. GIT: git branch [branch-name] - creates new branch
10. GIT: git checkout - switch to another branch
11. GIT: git status - show modified files in working directory
12. GIT: git add [file] - add a file to your next commit
13. GIT: git commit -m "[message]" - commit your staged content as a new commit
14. GIT: git push - transmit local branch commits to the remote repository branch
15. GIT: git merge [branch] - merge the specified branch's history into the current branch
