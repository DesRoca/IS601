Module 1: Assignment-Linux and GIT Command Cheat Sheet

Linux:
1. ls - list contents of directory
2. cd - change directory
3. mkdir - create directories 
4. pwd - get path of present directory 
5. mv - move or rename files
6. rm - delete files or directories
7. cat - display file contents in terminal 
8. echo - print text or variables in terminal 
9. top - get information about running processes
10. poweroff - shut down computer
11. restart - restart computer
12. ip - gets ip information for physical or virtual machine
13. printenv - print a perticular environment variable to console
14. export - export environment variables
15. env - display all environment variables

GIT: 
1. git branch - list your branches
2. git branch -b [branch-name] - creates new branch 
3. git checkout - switch to another branch 
4. git status - show modified files in working directory
5. git add [file] - add a file to your next commit
6. git commit -m "[message]" - commit your staged content as a new commit
7. git merge [branch] - merge the specified branch's history into the current branch
8. git push [alias] [branch] - transmit local branch commits to the remote repository branch
9. git pull - fetch and merge any commits from the tracting remote branch
10. git init - initialize an existing directory as a git repository
11. git log - show the commit history for the current active branch 
12. git fetch [alias] - fetch down all the branches from that git remote
13. git remote add [alias] [url] - add a git url as an alias
14. git reset --hard [commit] - clear staging area, rewrite working tree from specified commit 
15. git rebase [branch] - apply any commits of current branch ahead of specified one
16. git rm [file] - delete the file from project and stage the removal for commit
17. git mv [existing-path] [new-path] - change an existing file path and stage the move
