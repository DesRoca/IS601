Module 1: Assignment-Linux and GIT Command Cheat Sheet

Linux and GIT:
1. ls(Linux) - list contents of directory
2. cd(Linux) - change directory
3. mkdir(Linux) - create directories
4. pwd(Linux) - get path of present directory
5. cat(Linux) - display file contents in terminal
6. mv(Linux) - move or rename files
7. rm(Linux) - delete files or directories
8. git branch(GIT) - lists your branches
9. git branch [branch-name](GIT) - creates new branch
10. git checkout(GIT) - switch to another branch
11. git status(GIT) - show modified files in working directory
